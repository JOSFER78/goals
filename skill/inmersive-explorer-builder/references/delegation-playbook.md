# Delegation Playbook

Delegation is useful when tasks are independent and each has a precise deliverable.

## Research parallelism

Run up to 3–5 focused researchers in parallel when the project warrants it:
- domain facts;
- assets/licensing;
- technical stack;
- existing comparable implementations;
- education/UX.

Each researcher must return:
1. sources;
2. findings;
3. conflicts/uncertainties;
4. recommendations;
5. what they did not verify.

## Build parallelism

Do not parallelize edits to the same high-churn files. Prefer:
- one agent on data/config;
- one on isolated rendering module;
- one on tests/verification;
- one integrator to merge.

## QA agent

The verification agent should treat screenshots, running behavior, and acceptance criteria as evidence. It should not accept the implementation agent's self-report as proof.
