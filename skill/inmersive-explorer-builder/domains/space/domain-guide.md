# Space Domain Guide

Use primary/authoritative sources for ephemerides, mission status, spacecraft geometry, planetary data, and imagery. Evaluate JPL/NASA/ESA sources first.

Typical special needs:
- astronomical coordinate frames;
- epoch/time handling;
- huge dynamic range;
- relative/local coordinate systems;
- spacecraft tracking;
- planetary texture/DEM LOD;
- atmosphere/scattering;
- day/night lighting;
- timeline playback.

Tracer bullet: system → planet → moon → spacecraft with a reversible camera path and verified distances.
