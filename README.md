## 📖 Arquitectura Teórica & Didáctica

**GOALS** es una plataforma educativa de nueva generación diseñada para unificar áreas de estudio tradicionalmente aisladas (matemáticas, física, idiomas y ciencia) en un **perfil de aprendizaje único y persistente**.

### 🧠 Principios Pedagógicos
1. **No-Silos de Progreso**: El estudiante no pierde sus logros ni su racha al pasar de resolver ejercicios de matemáticas a explorar misiones espaciales en 3D o practicar inglés con un tutor de voz.
2. **Aversión a la Pérdida & Racha Diaria (Streak)**: Basado en la economía conductual (Kahneman & Tversky), la racha diaria activa encendida en llama 🔥 crea un hábito de conexión diario sostenible.
3. **Comprensión Espacial Fotorreal 3D**: Sustituye la memorización pasiva de libros impresos por simulaciones interactivas en Three.js con escalas reales del Universo de la NASA.
4. **Tutoría Multimodal con IA Adaptativa**: La inteligencia artificial recuerda los fallos cometidos en lecciones anteriores para adaptar automáticamente los ejercicios y explicaciones a las necesidades del estudiante.

### 1. 📚 Escuela IA
- **Tutor Multimodal con OCR**: Permite escanear con la cámara del dispositivo móvil fotos de deberes o cuadernos escritos a mano. La IA detecta ecuaciones (`2x + 5 = 15`) y texto manuscrito, guiando al estudiante paso a paso sin darle la respuesta directa.
- **Mapa Académico Conceptual**: Mapea el dominio de asignaturas (Matemáticas, Física, Biología, Historia) e identifica los temas a reforzar antes de exámenes.

### 2. 🌐 Idiomas Voz (AstroLingo Conversacional)
- **Tutor de Voz IA en Tiempo Real**: Inmersión hablada fluida con síntesis y reconocimiento de voz.
- **Memoria de Sesión**: El tutor de voz recuerda los errores fonéticos o gramaticales de charlas pasadas, adaptando el vocabulario técnico y científico a niveles B1/B2.

### 3. 🪐 AstroLingo 3D (Laboratorio Espacial)
- **Simulador 3D en 8 Escalas del Universo**: Desde la órbita de la Tierra y la Luna hasta exoplanetas, nebulosas y el agujero negro supermasivo M87*.
- **18 Lecciones Interactivas**: Artemis II, Starship Raptor 3, Telescopio James Webb, física orbital y tests de ordenación cronológica espacial.
- **54 Estrellas ⭐**: Sistema de puntuación estelar (0 a 3 estrellas por lección).

### 4. 🛡️ Verifica
- **Auditoría de Información Científica**: Herramienta de investigación que contrasta titulares y noticias en tiempo real contra bases de datos oficiales de la NASA y la ESA.

## 🎮 Sistema de Gamificación de Alto Engagement (Estilo Duolingo / Smartick)

### 🔥 1. Racha Diaria & Heatmap Semanal de 7 Días
- Evaluación dinámica de días consecutivos conectado (`streak`) mediante `checkStreak()`.
- **Calendario Semanal de Conexión (L M X J V S D)**: Visualizador visual en el perfil que marca los días activos de la semana con minillamas encendidas.

### ⭐ 2. Sistema de Estrellas (3 Estrellas por Lección)
- **3 Estrellas (100% acierto)**: Perfección absoluta (+Bonus máximo de XP).
- **2 Estrellas (80% - 99% acierto)**: Rendimiento excelente.
- **1 Estrella (60% - 79% acierto)**: Lección aprobada.
- Contador de estrellas global (hasta 54 ⭐ en AstroLingo).

### 🎯 3. Retos Diarios con Recompensa Instantánea de XP
Sistema interactivo de 5 misiones diarias con botón de **reclamación instantánea de XP**:
1. 🔥 **Racha de Fuego** (Alcanzar 3 días de racha) ➔ `+50 XP`
2. ⭐ **Dominio de Artemis** (3 estrellas en Lección 1) ➔ `+100 XP`
3. 📖 **Lectura Cósmica** (Completar 2 lecciones) ➔ `+75 XP`
4. 🚀 **Explorador 3D NASA** (Realizar test o simulador) ➔ `+120 XP`
5. 🏆 **Examen Perfecto** (Superar test con 100% aciertos) ➔ `+150 XP`

### 🌌 4. Rangos de Evolución del Estudiante
Barra de progreso acumulativa que evoluciona el rango astronómico del perfil:
- `0 - 99 XP`: **Novato de la Tierra 🌍** (Nivel 1)
- `100 - 299 XP`: **Cadete Espacial 👨‍🚀** (Nivel 2)
- `300 - 599 XP`: **Piloto Lunar 🚀** (Nivel 3)
- `600 - 999 XP`: **Comandante de Misión 🛸** (Nivel 4)
- `>= 1000 XP`: **Astrofísico Principal 🌌** (Nivel 5)

## 📱 UX/UI Compacto Móvil & Navegación Snap Scroll

1. **Diseño Ultra-Compacto ("Compactadito")**:
   - Menús y modales adaptados a smartphones con densidad de información alta sin saturación.
   - Pestañas horizontales fluidas en el `ProfileModal` (`⚡ Retos`, `🔥 Racha & ⭐`, `👤 Perfil`, `🪐 Astro`, `⚙️ Admin`).
2. **Snap Scroll 100% Viewport Height (`h-[calc(100vh-89px)]` / `100dvh`)**:
   - Cada sección de la pantalla de inicio y la landing page imanta limpiamente al 100% de la altura visible tras descontar el Sticky Header.
   - Al pasar la rueda del ratón o deslizar con el dedo en dispositivos táctiles, la navegación salta suavemente bloque por bloque.

## 💻 Stack de Tecnologías & Arquitectura Técnica

### Frontend & UI
- **React 18.3**: Librería de componentes reutilizables con Hooks.
- **TypeScript 5.4**: Tipado estricto de datos y modelos.
- **Vite 5.4**: Entorno de desarrollo ultra-rápido y bundler de producción.
- **Tailwind CSS 3.4**: Framework CSS utilitario con tokens personalizados de Glassmorphic y Neón.
- **Lucide React**: Biblioteca de iconos vectoriales SVG.

### Motor 3D & Gráficos
- **Three.js 0.165**: Renderizado 3D WebGL a 60 FPS con iluminación procedimental, texturas de la NASA y controles de órbita (`OrbitControls`).

### Backend, Nube & Persistencia
- **Firebase Auth v10**: Autenticación con Google OAuth (logo oficial SVG de 4 colores) y correo/contraseña.
- **Firestore Cloud Database**: Documentos sincronizados `users/{uid}` para almacenamiento en la nube.
- **LocalStorage Sincronizado**: Persistencia offline inmediata (`goals_data_<uid>` y `al_data_<uid>`).

### Comunicación Inter-Frame (Host React ↔ Iframe HTML5)
- Protocolo `window.postMessage` bidireccional que conecta `AstroExperience.tsx` con `astrolingo-app.html`, notificando eventos `TEST_COMPLETED`, `CLAIM_RETO` y `STEP_COMPLETED` al instante.

### Emulación & App Nativa Móvil
- **Capacitor 8 border**: Empaquetado nativo para Android APK v2.0 (`@capacitor/android`, `@capacitor/core`).

## ⚡ Guía de Instalación y Ejecución Local

### Requisitos Previos
- **Node.js**: Version 18.0.0 o superior.
- **npm**: Version 9.0.0 o superior.

### 1. Clonar el Repositorio
```bash
git clone https://github.com/usajosefernan-cmd/astrolingo.git
cd 10_goals
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Ejecutar Servidor de Desarrollo
```bash
npm run dev
```
La aplicación estará disponible en `http://localhost:3000`.

### 4. Compilar para Producción
```bash
npm run build
```
Genera los archivos optimizados dentro del directorio `dist/`.

### 5. Empaquetar para Android Nativo (Capacitor)
```bash
npx cap sync android
npx cap open android
```
