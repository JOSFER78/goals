## 3. FACTOR DE ARMONÍA DE SHANNON Y FÓRMULA DE XP UNIVERSAL

Para premiar el aprendizaje integral y evitar el estancamiento mono-materia:

$$\mathbf{p} = \left( p_{\mathcal{S}}, p_{\mathcal{B}}, p_{\mathcal{F}}, p_{\mathcal{Y}}, p_{\mathcal{C}} \right) \quad \text{donde } p_i = \frac{\text{XP}_i + \epsilon}{\sum_{j=1}^5 (\text{XP}_j + \epsilon)}$$

$$H(\mathbf{p}) = -\sum_{i=1}^5 p_i \log_5(p_i) \quad \implies \Phi_{\text{harmony}}(\mathbf{p}) = 1.0 + 0.5 \cdot H(\mathbf{p}) \in [1.0, 1.5]$$

$$\mathcal{U}_{XP} = \left( \sum_{d=1}^5 \text{XP}_d \right) \times \Phi_{\text{harmony}}(\mathbf{p}) \times M_{\text{streak}} \times M_{\text{school}}$$
