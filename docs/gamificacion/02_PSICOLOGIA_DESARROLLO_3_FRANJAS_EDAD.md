## 3. ESPECIFICACIÓN POR FRANJA DE EDAD

### 3.1. Franja 1: Pequeños (6 a 8 años) — "El Explorador Curioso"
- **Criaturas Cosmo-Biológicas (*Astro-Critters*):** Cada concepto alberga una criatura dormida (ej. *Lumen* en el Sol, *Polvorín* en Marte) que despierta y evoluciona al resolver retos.
- **Astillero de Naves Táctiles:** Ensamblaje modular mediante arrastrar y soltar con animaciones suaves.
- **Regla Zero-Penalty:** Queda estrictamente prohibido restar puntos o emitir sonidos graves de error. El error genera atenuación visual suave y asistencia de la mascota.

### 3.2. Franja 2: Intermedios (9 a 11 años) — "El Constructor de Maestría"
- **Árbol de Habilidades Ramificado (*Branching Skill Tree*):** Especialización en Astrofísica, Ingeniería, Cartografía u Exobiología con Puntos de Talento (TP).
- **Economía de 3 Cristales (Silicio, Plasma, Materia Radiante):** Para craftear instrumental interactivo (telescopios espectroscópicos, aceleradores de partículas).
- **Misiones Semanales Dinámicas:** 3 expediciones semanales orientadas a la constancia y la resolución de problemas.

### 3.3. Franja 3: Pre-adolescentes y Jóvenes (12 a 15 años) — "El Estratega Autónomo"
- **Rechazo al "Babyish UI":** Estética de terminal de control de misión espacial JPL/NASA (Dark Glassmorphism).
- **Rangos Aeroespaciales:** De *Cadete* a *Flight Controller*, *Deep Space Specialist* y *Quantum Systems Architect*.
- **Logros de Alta Ingeniería:** *Deep Focus 45m*, *Bug Hunter*, *Algorithmic Precision 100%*.
- **Heatmap de Actividad:** Visualización de constancia de 52 semanas y radar de competencias de 6 ejes.

## 4. MOTOR DE FLUJO (CSIKSZENTMIHALYI FLOW ENGINE CON IRT 2PL)

Probabilidad de éxito según el modelo Item Response Theory (IRT):
$$P(\theta) = \frac{1}{1 + e^{-a(\theta - b)}}$$

- **Zona de Flujo Óptima:** $P(\theta) \in [0.70, 0.85]$.
- Si $P(\theta) < 0.60$ (Ansiedad): Se inyecta andamiaje socrático MAIEUTIC-4 L1 $\to$ L2 y representaciones visuales 3D.
- Si $P(\theta) > 0.90$ (Aburrimiento): Se eleva la dificultad o se propone un reto avanzado de indagación.

## 5. MOTOR DE AUDIO SINTETIZADO (WEB AUDIO API REAL)

```typescript
export class PedagogicalAudioEngine {
  private ctx: AudioContext | null = null;

  private getContext(): AudioContext {
    if (!this.ctx) {
      const AudioCtxClass = window.AudioContext || (window as unknown as { webkitAudioContext: typeof AudioContext }).webkitAudioContext;
      this.ctx = new AudioCtxClass();
    }
    if (this.ctx.state === 'suspended') this.ctx.resume();
    return this.ctx;
  }

  /** Acorde pentatónico Do Mayor para aciertos en Franja 1 (Cero estrés) */
  playExplorerSuccess(): void {
    const ctx = this.getContext();
    const notes = [523.25, 659.25, 783.99, 1046.50]; // C5, E5, G5, C6
    notes.forEach((freq, idx) => {
      const osc = ctx.createOscillator();
      const gain = ctx.createGain();
      osc.type = 'sine';
      osc.frequency.setValueAtTime(freq, ctx.currentTime + idx * 0.08);
      gain.gain.setValueAtTime(0.001, ctx.currentTime + idx * 0.08);
      gain.gain.exponentialRampToValueAtTime(0.2, ctx.currentTime + idx * 0.08 + 0.04);
      gain.gain.exponentialRampToValueAtTime(0.0001, ctx.currentTime + idx * 0.08 + 0.45);
      osc.connect(gain);
      gain.connect(ctx.destination);
      osc.start(ctx.currentTime + idx * 0.08);
      osc.stop(ctx.currentTime + idx * 0.08 + 0.5);
    });
  }
}
```
