# ♿ 09. ACCESIBILIDAD UNIVERSAL (DUA 3.0) Y NEUROINCLUSIÓN EN IDIOMAS
## Adaptaciones para Dislexia Lingüística, TDAH, Mutismo Selectivo y Baja Visión

**Especialidad:** Inclusión Lingüística y Accesibilidad DUA 3.0  
**Conformidad:** WCAG 2.2 Nivel AAA  

---

## 1. ADAPTACIONES PARA DISLEXIA LINGÜÍSTICA
- **Fuentes Optimizadas:** Soporte tipográfico para *OpenDyslexic* y *Atkinson Hyperlegible* con espaciado de caracteres a 0.08em.
- **Sincronizador Text-to-Speech (TTS):** Resaltado en tiempo real palabra por palabra (`onboundary`) con velocidad ajustable de 0.6x a 1.2x.
- **Silabeo Coloreado de Palabras Nuevas:** Segmentación morfológica (*un · be · liev · a · ble*).

---

## 2. ADAPTACIONES PARA TDAH Y MUTISMO SELECTIVO
- **Micro-Conversaciones:** Turnos de habla limitados a $<15\text{ segundos}$ para mantener la atención sostenida.
- **Modo Input Alternativo (Mutismo Selectivo / Ansiedad Social):** El estudiante puede responder mediante selección táctil de tarjetas semánticas o transcripción escrita antes de dar el paso a la producción vocal.
- **Cero Temporizadores de Estrés:** Eliminación de cuentas regresivas punitivas en actividades orales.
