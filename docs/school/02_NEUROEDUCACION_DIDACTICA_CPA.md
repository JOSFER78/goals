## 1. LAS 6 TÉCNICAS DE ESTUDIO CON MAYOR EVIDENCIA CIENTÍFICA

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                   LAS 6 TÉCNICAS DE ESTUDIO MAESTRAS BASADAS EN EVIDENCIA EMPÍRICA                    │
├────────────────────────────┬───────────────────────────────────────────────────────────────────────────┤
│ 1. Retrieval Practice      │ Evocación activa desde la memoria sin mirar apuntes (Testing Effect).     │
│ 2. Spaced Repetition (FSRS)│ Distribución óptima del repaso en el tiempo según la curva de retención.  │
│ 3. Interleaving Practice   │ Alternancia de tipos de problemas para aprender a discernir estrategias. │
│ 4. Dual Coding (Paivio)    │ Doble anclaje simultáneo: representación visual esquemática + verbal.    │
│ 5. Elaborative Interrog.   │ Preguntas "¿Por qué es verdad esto?" y conexión con conocimientos previos.│
│ 6. Feynman Technique Kids  │ Explicar el concepto con palabras tan simples que un niño de 7 años lo entienda.│
└────────────────────────────┴───────────────────────────────────────────────────────────────────────────┘
```

### 1.1 Retrieval Practice (Evocación Activa / Test Effect)
- **Fundamento:** Cada vez que el cerebro recupera un recuerdo de la memoria a largo plazo, la huella sináptica se reconsolida y se vuelve más resistente al olvido (Roediger & Karpicke, 2006).
- **Implementación en GOALS:** El tutor nunca dice *"Léete este párrafo y luego te pregunto"*. En su lugar, presenta un reto socrático directo: *"Cierra los ojos un segundo: ¿cuáles eran los tres componentes del aire que respiramos?"*.

### 1.2 Spaced Repetition (Repaso Espaciado con Algoritmo FSRS)
- **Fórmula de Retención:**
  $$R(t, S) = \left(1 + \text{factor} \cdot \frac{t}{S}\right)^{-1}$$
  Donde $S$ es la estabilidad del recuerdo y $t$ el tiempo transcurrido. Tras cada sesión de recuperación exitosa, la estabilidad $S$ se incrementa de forma multiplicativa.

### 1.3 Interleaving Practice (Práctica Intercalada vs Bloqueada)
- **El Problema de la Práctica en Bloque:** Si un alumno hace 20 ejercicios seguidos de "restas con llevada", no aprende *cuándo* restar, solo repite mecánicamente un algoritmo.
- **La Solución Interleaving:** GOALS mezcla problemas de suma, resta, multiplicación y fracciones en una misma sesión. El alumno entrena la habilidad de **discernimiento heurístico**.

### 1.4 Dual Coding Theory (Codificación Dual)
- Todo concepto abstracto se apoya en una representación gráfica limpia: diagramas de bloques, modelos de barras, esquemas de flujo o ilustraciones anatómicas vectoriales.

### 1.5 Elaborative Interrogation (Interrogación Elaborativa)
- Ante una afirmación (*"Los metales son buenos conductores del calor"*), el tutor formula: *"¿Por qué crees que una cuchara de metal se calienta más rápido que una de madera cuando removemos la sopa caliente?"*.

### 1.6 Feynman Technique Infantil
- El alumno debe dictar por voz o escribir una explicación ultraclara para un personaje novato. Si usa jerga técnica sin comprenderla (*"porque ocurre la homeostasis"*), el tutor le pide: *"Explícaselo a tu amigo robot sin usar palabras raras"*.

## 3. MÉTODO SINGAPUR CPA Y HEURÍSTICA DE GEORGE PÓLYA

```
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │                 MÉTODO SINGAPUR CPA (JEROME BRUNER)                         │
  ├──────────────────────┬─────────────────────────────┬────────────────────────┤
  │ 1. FASE CONCRETA     │ 2. FASE PICTÓRICA           │ 3. FASE ABSTRACTA      │
  │ Manipulación física  │ Modelo de Barras / Esquema  │ Notación simbólica     │
  │ de objetos/regletas. │ visual de cantidades.       │ y ecuaciones formales. │
  └──────────────────────┴─────────────────────────────┴────────────────────────┘
```

### Los 4 Pasos Universales de George Pólya:
1. **Comprender el problema:** Identificar la incógnita, los datos dados y las restricciones.
2. **Concebir un plan:** Buscar patrones, resolver un problema semejante más sencillo o dibujar un diagrama de barras.
3. **Ejecutar el plan:** Realizar los cálculos comprobando cada paso lógico.
4. **Mirar hacia atrás (Visión Retrospectiva):** Comprobar si el resultado tiene sentido físico en la realidad y reflexionar sobre la estrategia utilizada.

## 4. ENTRENADOR DE METACOGNICIÓN Y SEMÁFORO DE CALIBRACIÓN

Al finalizar cada ejercicio o tema, el alumno calibra su nivel de dominio:
- 🟢 **Verde (Dominio Alto):** *"Lo he entendido perfectamente y sabría explicárselo a un compañero"*.
- 🟡 **Amarillo (Dominio Medio):** *"Sé hacerlo, pero todavía necesito mirar alguna fórmula o dudo en algún paso"*.
- 🔴 **Rojo (Dominio Bajo / Duda):** *"Me he atascado y no sé por qué sale este resultado"*.

El tutor cruza la autoevaluación subjetiva del alumno con su precisión matemática real para corregir tanto el **Efecto Dunning-Kruger** (sobreestimación) como el **Síndrome del Impostor** (infravaloración).
