## 2. FILTRO ANTI-HYPE Y MÉTRICA DE RELEVANCIA PEDAGÓGICA (PTI $\ge 0.72$)

Para descartar notas de prensa publicitarias, afirmaciones pseudocientíficas o modas efímeras, cada publicación se evalúa mediante el **Índice de Transferencia Pedagógica (*Pedagogical Transfer Index - PTI*)**:

$$\text{PTI} = 0.35 \cdot \mathcal{S}_{\text{fundamento}} + 0.30 \cdot \mathcal{S}_{\text{código}} + 0.25 \cdot \mathcal{V}_{\text{científica}} - 0.20 \cdot \mathcal{H}_{\text{hype}}$$

- $\mathcal{S}_{\text{fundamento}}$: Presencia de formulación matemática formal o pruebas algorítmicas claras.
- $\mathcal{S}_{\text{código}}$: Existencia de implementación de código abierto verificada y reproducible.
- $\mathcal{V}_{\text{científica}}$: Respaldo de la comunidad académica (citas, conferencias NeurIPS, ICML, ICLR, CVPR, ACL).
- $\mathcal{H}_{\text{hype}}$: Detección de lenguaje publicitario sin datos empíricos (*"revolución mágica"*, *"inteligencia infinita"*).

**Regla de Admisión:** Solo los papers con $\text{PTI} \ge 0.72$ se envían al pipeline de destilación curricular.

## 4. MOTOR DE EVOLUCIÓN DE GRAFOS DAG SIN ROMPER PRERREQUISITOS

La estructura curricular de GOALS AI Lab se modela como un **Grafo Dirigido Acíclico $\mathcal{G} = (\mathcal{V}, \mathcal{E})$**, donde cada nodo $v \in \mathcal{V}$ representa una unidad o concepto y cada arista dirigida $(u, v) \in \mathcal{E}$ define un prerrequisito obligatorio.

```typescript
// Algoritmo de Inserción No Destructiva de Kahn en O(|V| + |E|)
export class CurriculumDAGManager {
  /**
   * Inserta un nuevo concepto de vanguardia garantizando que el grafo sigue siendo un DAG acíclico
   */
  public static insertVanguardNode(
    graph: CurriculumDAG,
    newNode: CurriculumNode,
    prerequisiteIds: string[]
  ): { success: boolean; updatedGraph?: CurriculumDAG; error?: string } {
    // 1. Clonar grafo para verificación transaccional
    const candidateGraph = JSON.parse(JSON.stringify(graph));
    candidateGraph.nodes[newNode.id] = newNode;
    
    for (const prereqId of prerequisiteIds) {
      if (!candidateGraph.nodes[prereqId]) {
        return { success: false, error: `Prerrequisito inexistente: ${prereqId}` };
      }
      candidateGraph.edges.push({ from: prereqId, to: newNode.id });
    }

    // 2. Comprobar aciclicidad con Algoritmo de Kahn
    const inDegree: Record<string, number> = {};
    for (const nodeId in candidateGraph.nodes) inDegree[nodeId] = 0;
    for (const edge of candidateGraph.edges) inDegree[edge.to]++;

    const queue: string[] = [];
    for (const nodeId in inDegree) {
      if (inDegree[nodeId] === 0) queue.push(nodeId);
    }

    let visitedCount = 0;
    while (queue.length > 0) {
      const current = queue.shift()!;
      visitedCount++;

      const outgoing = candidateGraph.edges.filter((e: any) => e.from === current);
      for (const edge of outgoing) {
        inDegree[edge.to]--;
        if (inDegree[edge.to] === 0) queue.push(edge.to);
      }
    }

    const totalNodes = Object.keys(candidateGraph.nodes).length;
    if (visitedCount !== totalNodes) {
      return { success: false, error: 'La inserción generaría una dependencia circular en el currículo.' };
    }

    // 3. Marcado no invasivo para alumnos que ya superaron el nivel
    newNode.status = 'discovered_vanguard_update';
    return { success: true, updatedGraph: candidateGraph };
  }
}
```
